## Materials in This Folder

### 1. `CUDA-Q_Local_Deployment_Guide.pdf` — *Run CUDA-Q on your own machine*

A quick-start companion for setting up CUDA-Q **locally** after the tutorial. Inside you'll find:

- Two install paths: **PyPI** (lightweight) and **container** (recommended, including WSL2 notes for Windows users)
- A worked example using **Miniconda + pip** so you can have a clean `cudaq-env` running in minutes
- Pointers to the official CUDA-Q docs, GitHub repo, and **CUDA-Q Academic** for deeper dives

> If you'd like to reproduce the exact tutorial environment offline, the same `nvcr.io/nvidia/quantum/cuda-quantum:cu13-0.14.0` image used today is referenced in this guide.

### 2. `CUDA-Q_on_Brev.pdf` — *Try CUDA-Q on the cloud, in one click*

A short walkthrough of running CUDA-Q on **NVIDIA Brev**, with two pre-built one-click "Launchables":

- **CUDA-Q Application Hub** (VM mode): sample applications across quantum chemistry, AI, and optimization
- **CUDA-Q Launchable** (Docker mode): a clean container-based start

> **Heads-up:** You don't need this for today's setup — your workshop Brev instance is already preconfigured. This guide is for **after** the tutorial, when you get started on your own.
